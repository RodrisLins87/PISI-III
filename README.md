# PISI-III

Este repositório é destinado ao desenvolvimento do projeto da disciplina **Projeto Interdisciplinar para Sistemas de Informação III (PISI-III)**, desenvolvida de forma coordenada com a disciplina **Desenvolvimento de Sistemas de Informação**, da Universidade Federal Rural de Pernambuco (UFRPE), no curso de **Bacharelado em Sistemas de Informação**.

As disciplinas são ministradas pelos docentes **Gabriel Alves** e **Maria da Conceição**.

# DESENVOLVIMENTO

Por enquanto, este repositório funciona como um *placeholder*, até que a equipe defina a ideia e os requisitos do projeto.

A estrutura e o conteúdo do repositório serão atualizados conforme o projeto for desenvolvido.
